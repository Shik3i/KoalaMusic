# Scope

## In

- Android 8.0+ native application using Kotlin and Compose
- OpenSubsonic plus required legacy Subsonic compatibility
- one active profile, with profile-isolated multi-profile storage
- metadata caching, local search, persistent queue, Media3 playback
- honest degraded browsing when the server is unavailable
- explicit per-profile local HTTP opt-in
- user-generated sanitized diagnostics

## Out of the initial MVP

Downloads, local files, podcasts, audiobooks, radio, Jellyfin, Plex, SMB,
WebDAV, cloud drives, Spotify/Apple Music streaming, crossfade, advanced DSP,
Android Auto UI, casting, TV, Wear, web, desktop, and Koala Connect.

No unused generic provider framework or placeholder clients are created.
