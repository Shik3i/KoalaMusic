# Product

KoalaMusic is a native Android-first player for user-owned OpenSubsonic
libraries. Navidrome is the primary compatibility target. The experience should
be calm, fast, artwork-led, adaptive, and recognizably KoalaMusic rather than a
Spotify clone.

The user owns the server, credentials, library metadata, listening history, and
recommendation signals. KoalaMusic has no account service, central backend,
telemetry, advertising, or silent third-party metadata traffic.

Success for the first release means one reliable path: configure a server,
synchronize a useful local read model, browse an album, stream a track in the
background, control it from Android, and restore the queue after process death.

The initial public distribution target is Google Play only. F-Droid, GitHub
Releases, and Obtainium compatibility remain roadmap options after the first
release.
